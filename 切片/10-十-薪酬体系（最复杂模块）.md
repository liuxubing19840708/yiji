### 10.2 员工薪酬详情（截图 32/33/36）
- 头部：头像+姓名+岗位；已结 ¥0 / 未结 ¥9638
- 三 Tab：**工资 / 计数 / 固定工资**
  - **工资**（截图 39/40）：子 Tab 按日期查看（默认）/ 按裁床查看 / 汇总查看；按日列表：10-12 64(件)/4扎 ¥480、10-11 114/6 ¥855…（件数=Σ登记数量，扎数=Σ菲票数，金额=Σ件数×单价）
  - **计数**（截图 38）：子 Tab 按日期查看/按裁床查看 + 「按日↔汇总」toggle
  - **固定工资**（截图 33）：列表为空（固定工资人员的月/日工资发放记录）
- 底部按钮：**结算记录 | 申请结算**
- **薪酬管理详情（编辑页，截图 36）**：固定工资金额输入（0.00）+ **按日/按月** toggle + 入职时间（可空）+ **停职** toggle + **扣除金额**（−，绿）/ **发放奖励**（+，橙）+ 保存
  - 逻辑：固定工资 = 底薪，与计件并行；停职=暂停登记权限且不参与结算；扣除/奖励为一次性调整项，逐笔记录（金额、事由、操作人、时间），计入总工资

### 10.3 工资结算流程（管理员，截图 37）
- 确认页：完成时间区间、金额汇总 ¥86643.50、**逐员工金额网格**（周莉华9638 / 卢文9124.5 / 彭芹7935.5 … 江文萍120）、底部 取消/确认
- 逻辑：结算 = 把区间内所有「未结」登记记录批量打上 `settlement_id` 并生成结算单 `settlement(id, company_id, amount, employee_count, period_start, period_end, created_by, status)`
- 结算后对应登记记录变「已结」，员工未结清零、已结增加

- 日期范围筛选（2026-04-12–2026-10-12 ▾）、当前金额：¥380484.9

### 10.5 申请结算（员工发起）与审核（截图 35）
- 员工端「申请结算」按钮 → 填金额（默认未结金额）+ 说明文字 → 提交
- **审核明细页**：筛选（全部▾ + 日期区间▾ + 员工筛选>）、当前金额、双 Tab **审核记录 / 发放记录**
- 卡片：申请结算 / 申请时间：2026-09-09 / 姓名：徐利兰 / 电话：15072136736 / 金额：¥256.00 / 说明："昨天做的，今天说没有多少活叫不出去" + 状态章「**已作废**」
- 状态机：`待审核 → 已审核(待发放) → 已发放`；旁路：`已作废`（作废需理由）、`已拒绝`
- 发放记录 = 实际打款流水（线下现金/微信转账后管理员标记发放，记录发放人/时间）

### 10.6 我的薪酬 / 订单薪酬（首页模块，员工/管理员视角）
- 我的薪酬：员工本人未结/已结/总工资 + 按日明细 + 申请结算入口
- 订单薪酬：按订单/款式维度汇总工资支出（管理成本核算用）

### 10.7 金额计算规则（关键）
- 计件工资 = Σ(登记数量 × 工序单价)；单价来源优先级：床次订单工序单价 > 款式工序单价 > 工序默认价
- 无单价工序数 > 0 时提示管理员补价（截图 41 有该统计位）
- 金额精度：全程 DECIMAL，展示保留 1~3 位小数，结算汇总时四舍五入到分并在结算单快照金额（防后续改价影响历史）
- **隐藏员工工资**（系统设置 OFF）：关闭后普通员工互不可见他人工资；**隐藏款式总单价**（ON）/ **隐藏扫菲单价**（OFF）：控制单价字段的显示层级
