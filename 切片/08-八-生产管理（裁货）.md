## 八、生产管理（裁货）

### 8.1 功能需求（截图 42/43）
- 搜索：款号/床次/名称/客户 + 漏斗筛选；筛选行：订单类型 ▾ / 全部 ▾ / 客户 ▾ / 更多 ▾
- 卡片：款式图、床次 285、款号 26599-2、件数 840、工序数 1道、日期 2026-10-12、已完成工序数 0（橙色）+ 进度条 + 「按扎号查看 >」
- 底部操作条：**锁住** toggle / **裁完** toggle / **裁货明细** 按钮
- 卡片 ⋮ 菜单：**修改 / 打印 / 订单工序 / 分货模式 / 删除**
- 列表按床次倒序（285、284、283…），284 显示已完成 36 + 进度条

### 8.2 实现逻辑
- 数据模型：`production(id, company_id, style_id, bed_no, total_qty, order_type, customer_id, is_locked, is_cut_done, created_at)`
- **锁住**：锁定后不可再扫菲登记（防错登/已结款订单），锁定需管理员权限；解锁写日志
- **裁完**：标记该床次裁货完成，之后不允许增加扎数；「默认裁完」系统开关=编菲后自动置裁完（截图 8）
- **订单类型 / 分货模式**：订单类型区分自产/外发等；分货模式决定菲票数量如何分配到工序（整件 vs 分工序分摊）
- **订单工序**：配置该床次包含的工序及单价（可覆盖款式默认工序）
- **按扎号查看**：展开该床次所有菲票扎列表，每扎显示状态（未登记/部分登记/完成）
- **裁货明细**：颜色×尺码矩阵汇总视图（与编菲矩阵同组件复用）
- 进度条 = 已完成工序数/总工序数 或 已登记件数/总件数（按分货模式定）
- 删除：仅有登记记录时需先撤销全部登记，二次确认
