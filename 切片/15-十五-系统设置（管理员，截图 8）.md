## 十五、系统设置（管理员，截图 8）

13 项开关/选项及语义：

| 设置项 | 默认 | 实现语义 |
|---|---|---|
| 默认裁完 | OFF | 编菲保存后自动置「裁完」 |
| 只能撤销当月登记 | ON | 撤销登记校验 `registered_at` 在当月内 |
| 隐藏扫菲单价 | OFF | 扫菲确认页不显示单价（防员工比价） |
| 过滤数量为0的菲票 | ON | 列表/统计剔除 qty=0 的菲票 |
| 显示裁货总数 | ON | 生产卡片显示总件数 |
| 隐藏款式总单价 | ON | 款式列表不显示总价 |
| 隐藏员工工资 | OFF | 非本人/非管理员不可见工资 |
| 未审核禁止登记 | OFF | 入职未审核员工不能扫菲 |
| 默认开启计数 | OFF | 登记时默认打开计数器模式 |
| 显示薪酬款式图片 | ON | 薪酬明细带款式缩略图 |
| 默认打印方式 | 云打印 | 蓝牙/云打印切换 |
| 云打印 | — | 云打印机管理入口 |
| 个性化通知 | ON | 消息推送开关 |

- 实现：`company_setting(company_id, key, value)` KV 存储；开关读写走一个批量接口；设置页一次拉取、批量保存；所有开关在服务端校验时生效（前端只控制显示）
