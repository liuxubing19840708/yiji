## 二、重划后的首页宫格（7 组）

```
组1 订单生产   订单管理 · 报价管理 · 生产管理 · 指定工序 · 工作中 · 款式管理 · BOM管理 · 物料管理
组2 车间计件   批量代登 · 协助扫菲 · 质检管理 · 外发管理 · 工序
组3 薪资对账   薪酬管理 · 我的薪酬 · 订单薪酬 · 完成汇总 · 应收管理
组4 供应链     轻量仓库 · 按床领料 · 暂收IQC · 供应商 · 出货管理
组5 经营报表   生产看板 · 成本管理 · 质量追溯
组6 协同档案   客户管理 · 员工管理 · 公司二维码
组7 系统       打印管理 · 日志管理 · 客户端日志
```

- **员工岗**不分组：仍 3 项（工序/我的薪酬/工作中）单组展示。
- 组内顺序 = 动线序（订单→生产→计件→薪资→供应链→报表→协同→系统）。
- 空组（该岗位全组无权限）整组隐藏。
- tabBar 不变：首页 / 扫菲 / 通知 / 我的 / AI问报。

## 三、与衣协同的结构差异（有意保留）

1. **供应链独立成组**（衣协同并入进销存应用商店）：我方采购→暂收→IQC→入库→领料
   →出货全链自研且打通成本，是强项，值得独立组。
2. **AI问报放 tabBar**（衣协同无对标）：日报问答是高频入口，不进宫格。
3. **扫码独立 tab**：车间工人主入口，衣协同以办公室 PC 为主我方以手机车间为主。
4. **应用商店不做**：自研全覆盖，避免插件质量不可控。
