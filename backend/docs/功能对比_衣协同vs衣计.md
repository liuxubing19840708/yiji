# 功能逐项对比：华遨衣协同 vs 衣计（2026-11-04）

> 依据：竞品教学视频逐帧分析（71 帧 + 12 张接触表，`uitest/tmp_frames/`，帧号 f_007/f_016/f_024/f_026/f_035/f_040/f_049/f_053/f_057/f_062/f_066/f_067/f_071 等）与我方代码事实。
> 分组沿用《功能重划分_衣协同对齐.md》七组骨架。
> 结论标记：【对齐】能力相当 / 【领先】我方强 / 【借鉴】竞品有我方无，建议吸收 / 【独有】我方差异化。

## 组1 订单生产

### 1.1 工厂订单录入（f_007）

- **竞品做法**：新建工厂订单弹窗——订单图片（支持 Ctrl+V 粘贴）、款号/款名/单位/单价、客户下拉、翻单号、「隔产翻单」开关、下单日期/预交货期/跟单员下拉、颜色 chip 回车添加 + **每色可挂颜色图片**、尺码 chip 回车添加、底部「下单数量」颜色×尺码矩阵逐格填写 + 合计行自动求和。
- **我方做法**：订单管理（orders 域）+ 款式管理分离，订单挂 style 外键；数量走订单 items（颜色/尺码/数量行）；2026-10-21 已支持款式多图 9 张。
- **差异**：①竞品订单/款式一体填写（快但杂）；我方订单引用款式主档（规范但多一步）。②竞品颜色×尺码**矩阵**录入 + 小计/合计自动算；我方为行式 items。③竞品有「跟单员」「预交货期」字段，我方交期在 production 域。
- **竞品优点**：一屏录完小订单，矩阵录数量对打版师傅直观。
- **我方优点**：款式主档复用（多订单共用款号不重录）、多图 9 张、订单→菲票联动查询、报错中文化。
- **借鉴建议**：订单数量录入可升级为颜色×尺码矩阵组件（P2 级体验项，不必急）；跟单员字段可加。

### 1.2 款式工序配置（f_016）

- **竞品做法**：款式详情内嵌「款式工序」开关区块——每工序：环节/工时/单价/编制工价/部位/**是否计数**/**关键工序**/**指定规格**/**工序视频**（均为行内 toggle），底部合计行自动算单价合计；旁边有面料/辅料选择、尺寸表、导入 Excel；另有「是否开放工价」开关（对员工隐藏单价）。
- **我方做法**：工艺路线在工序模板 + 款式工艺字段（P4 已交付）；工价隐藏 GAP-6 已交付（salary 域 hide_price 口径）；视频上传 P4 已交付；关键工序 GAP-8 已交付（看板 key_only 过滤）。
- **差异**：竞品把工序配置塞进款式详情（一站式）；我方工序模板独立（复用强）。竞品「是否计数」= 我方工序是否计件（assigned/计价链已覆盖）。
- **竞品优点**：单款配置动线短，工序行内开关直观。
- **我方优点**：工序模板跨款复用 + 计价链标注（床次>款式>默认，P1-3 已交付）、工价隐藏按岗位而非全局开关（粒度细）。
- **借鉴建议**：【对齐偏领先】。「指定规格/部位」字段我们暂缺，属低频，缓。

### 1.3 裁床 / 编菲 / 打票（f_024、f_026）

- **竞品做法**：
  - 表格编菲弹窗（f_024）：床次/周数配比/扎号前缀/实裁日期/裁单人，颜色×尺码 chip 展示，**逐行录「层数」**，系统按层数×下单量自动生成扎。
  - 订单追踪页（f_026）：导入Excel / 预裁床单 / 手动编菲 / **一键开菲** 四按钮；裁床编菲表（序号/菲票编号/扎号/颜色/尺码/数量/操作：打印·更多）+ 右侧实裁数量矩阵（颜色×尺码，含已裁/合计对比）；行操作：编辑/增加新套/拆分新套/打印菲票/打印裁床单/删除。
  - 菲票打印弹窗（f_026 前景）：床次输入、模板选择（普意忠标等）、**多张打印**开关。
- **我方做法**：生产管理开裁向导（床次创建→裁片→自动切扎）+ 编菲打票 + 云打印管理（printer 域）+ 标签预览组件（label-preview）+ 打印历史（2026-10-21）。
- **差异**：①竞品「按层数」切扎；我方按每扎数量/扎数切扎。②竞品有「拆分新套/增加新套」补扎操作；我方支持任意合并收敛 + 满扎徽标 + 手输码兜底。③竞品多模板选择；我方单一标签模板+云打印机。
- **竞品优点**：层数法贴合大货裁床习惯（一床 N 层出 N 扎）；实裁数量矩阵回填直观。
- **我方优点**：**扫码即打**（车间手机直达，竞品全流程 PC）；满扎校验 + 离线暂存；云打印免驱动。
- **借鉴建议**：「按层数切扎」可作为切扎方式二选项（低优先）；「拆分新套」我方已有等价合并/收敛能力。

### 1.4 报价管理 【独有】

- 竞品无报价域。我方 quotation（101 断言）+ 报价转订单预填（orders?quote=）。**领先**。

## 组2 车间计件

### 2.1 车间进度（f_035）

- **竞品做法**：进度环（生产进度 0%~8.33% + 「关键工序」开关切换口径）+ 左侧工序进度条列表（1.裁剪 8.33%…已完成 N 件）+ 主区**三视图 tab**：按扎显示（默认）/按工序显示/员工工资统计；顶部筛选：床次/扎号/颜色/尺码；每扎卡片：扎号/排单号/床次/尺码/数量/颜色/备注 + 工序价目（裁剪¥5/车缝¥6/洗水¥2/包装¥0.5）；扎卡操作：**修改数量 / 撤销**；右上「批量登记」「更多操作」。
- **我方做法**：生产看板六维 dim（dashboard/dim 端点 + 六 chip，2026-10-23）+ 关键工序过滤（GAP-8）+ 完成度矩阵（显示扎号）+ 追溯钻取。
- **差异**：竞品是「订单维进度总览」；我方是「多维看板」。竞品有按扎卡片+行内修改/撤销，我方改数在记录页。
- **竞品优点**：按扎卡片视图对车间现场查扎非常直观；进度环一句话报进度。
- **我方优点**：六维（款式/订单/工序/员工/床次/颜色尺码）远超竞品三视图；实时；钻取到菲票。
- **借鉴建议**：看板增加「按扎卡片」视图（把完成度矩阵升级为扎卡 + 工序价目），是本次对比中**最值得抄的一个 UI**。

### 2.2 批量登记 / 协助登记（f_040）

- **竞品做法**：批量登记弹窗——按床次/扎号列出待登扎（序号/扎号/菲票编号/颜色/尺码/数量/**状态列：登记成功(绿)/正在登记/等待中**），选工序→确定→逐扎显示登记进度，失败可重试。
- **我方做法**：GAP-2 批量代登已交付（batch-register 页）+ 协助扫菲（assist，probe 通用）。我方语义：批量代登按菲票勾选+工序+数量提交，**部分成功有明确回执**（成功/失败分列，失败原因逐条）。
- **差异**：竞品是「全选即登记」的进度流；我方是「勾选+确认」的事务流。竞品状态列实时滚动更好看；我方部分成功语义更严谨（竞品失败语义视频未演示）。
- **借鉴建议**：【对齐】。竞品的状态滚动可加为提交中动画，纯体验项。

### 2.3 修改数量（f_049）【借鉴】

- **竞品做法**：修改数量弹窗——调整后数量 + **调整原因（必填）** + **「同步更新已登记」开关**（改扎量后联动改已登记记录）。
- **我方做法**：GAP-3 改数填原因已交付（记录页改数留痕 audit）；但**无「同步更新已登记」联动**——改扎量后已登记数量需人工核对。
- **差异**：竞品多一个联动开关。
- **竞品优点**：实裁<下单时一键收缩已登量，避免超量计件。
- **我方优点**：我方改数留痕（audit_log）+ 原因必填比竞品（视频未见留痕展示）更严谨。
- **借鉴建议**：在改数弹窗加「同步收缩已登记数量」开关（后端事务内 trim 已登记记录），**中优先级**。

### 2.4 质检管理（f_066）【对齐，GAP-1 已交付】

- **竞品做法**：全列展示（图片/成品/工厂订单/款号/款式名/款名/菲票编号/返修原因/状态/返修数量/收回数量/计件数量/生产人/质检人/质检时间）+ 操作（详情/收货/完成/删除）+ 导出Excel。
- **我方做法**：quality app：登记（选菲票+工序+缺陷数+原因）→ 收回 → 完成；删除拒绝已完成；导出 Excel；26/26 断言。
- **差异**：列集基本一致；竞品多「图片/成品列」。竞品「质检人」= 登记人，我方 producer/inspector 分立更清楚。
- **借鉴建议**：【对齐】。质检列表加款式图片列（低优）。

### 2.5 外发管理（f_044 前后）【对齐，GAP-5 已交付】

- 竞品：外发管理（发出/收回/结算，计价在发出）。我方：outsource 域 sent→partial→returned→settled，发出计价 OS 单号，26/26 断言。
- **差异**：竞品有发料三本账（发料/退料/耗料）；我方 P3 再做（已在文档中立项为纵深）。
- **借鉴建议**：【对齐】。

### 2.6 扫码动线 【独有·领先】

- 竞品全流程 PC 端操作，车间工人不动手；我方扫码 tab（扫菲→满扎徽标→手输码兜底→离线暂存）+ 员工自登。**结构性差异，保留**。

## 组3 薪资对账

### 3.1 薪资管理结构（f_053）

- **竞品做法**：四 tab——**工价单 / 日结统计 / 薪资管理 / 员工计件明细**；「按员工结算」+「费登详情」按钮。
- **我方做法**：薪酬管理（汇总卡+三按钮+员工卡）+ 我的薪酬 + 订单薪酬 + 完成汇总四个入口；四类工资（计件/固定/时计/反修）。
- **差异**：竞品有**日结统计**（按天出每人件数金额）独立 tab；我方日结散在完成汇总/看板。竞品有**工价单**导出打印入口。
- **借鉴建议**：完成汇总页已有 salary/completion 视图切换；「日结统计」可作为完成汇总的时间维度快捷 chip（低优）。

### 3.2 按订单结算（f_057）【借鉴】

- **竞品做法**：结算弹窗支持**按订单多选结算**（订单搜索 + 多选 + 备注），也支持按员工/按日期。
- **我方做法**：结算按期间（start~end）+ 按员工申请两条路；订单薪酬页是**查看**维度，不能按订单发起结算。
- **差异**：竞品支持按订单维度结算（订单尾数结清场景）。
- **借鉴建议**：结算入口加「按订单过滤」参数（结算该订单全部未结登记），**中优先级**——订单尾款结算是真实场景。

### 3.3 薪资条打印（f_062）【对齐，GAP-4 已交付】

- **竞品做法**：打印预览（打印机/份数/页面选择），结算明细表：日期/工厂订单/款号/工序/单价/数量/金额+合计。
- **我方做法**：payslip 页（结算明细逐员工条目 + wage_detail 快照优先）+ Excel 导出 + 云打印。
- **差异**：竞品直接出打印预览（PC 连打印机）；我方导出 Excel/云打印（手机生态）。
- **借鉴建议**：【对齐】。

## 组4 供应链 【独有·领先】

- 竞品视频未见进销存/领料/成本链（其应用商店另有进销存应用，未在本视频）。我方：采购→暂收→IQC→入库→按床领料（定额/超领硬拦）→出货→应收→成本（OrderCost 对账）全链。
- **结论**：结构性领先，无需借鉴。

## 组5 经营报表

### 5.1 报表中心（f_067、f_071）

- **竞品做法**：四张固定报表——工序生产对照表（四 tab + 模式显示完成数量 + 导出Excel + 逐扎行：孔号/颜色/尺码/菲票编号/数量/原数量/创建原因/各工序完成情况列）/订单计菲明细表/订单进度明细表/**按序生产工序表**（订单/款号/款名/工序名称/可登记数量）。
- **我方做法**：生产看板六维 + 完成汇总（款式→工序→菲票三级钻取）+ 成本管理 + 质量追溯 + AI问报（自然语言查数）。
- **差异**：竞品是固定四表导出 Excel；我方是可交互钻取 + AI 问答。「按序生产工序表」（= 各工序待登记量，派工参考）我方无直接对标——看板工序维显示完成量，不显「可登记数量」（= 扎量-已登量）。
- **竞品优点**：报表开箱即用、导出习惯好；「可登记数量」对派工头很实用。
- **我方优点**：AI问报降维打击（竞品查数要翻四张表）；三级钻取。
- **借鉴建议**：看板/完成汇总加「可登记数量 = 扎量 − 已登记」列（后端字段加一个，**中优先级**）。

### 5.2 对账结算（应收）【独有·领先】

- 竞品「对账结算」含应付（视频未展开）；我方应收核销/批量核销已交付，应付 P3。
