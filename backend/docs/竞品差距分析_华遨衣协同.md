## 一、竞品定位与形态

- **产品名**：华遨-衣协同，自称「SaaS 轻量级服装生产管理系统」，本视频为其「车间计件」模块操作教程。
- **形态**：**PC Web 优先**（浏览器 B/S，全程桌面端操作），手机扫菲只是登记通道之一（原话字幕：「工艺登记 电脑登记或手机扫菲登记」）。
- **左侧导航完整模块**：工作台 / 打版 / 订单生产（样菲流转选择、成衣组排序） / **车间计件**（工厂订单、裁床单、车间进度、薪资管理、外发管理、质检管理）/ **报表中心**（工序生产对照表、订单计菲明细表、订单进度明细表、裁床生产工序表）/ 协同中心 / 对账结算 / 应用商店 / 基础资料 / 系统设置 / 操作指南（站内帮助）。

## 二、竞品车间计件主流程（视频演示序）

1. **工厂订单**：全屏建单弹窗；星号必填；**商品图片可本地上传也可直接粘贴复制**；客户信息/单价/跟单人/预计交货日期；颜色尺码回车添加、颜色带图片；下单数量；**工序弹窗**：选择工序、工序价格、**「是否开放工价」开关**（控制单价是否对工人可见）、可继续增加工序行。
2. **裁床单**（状态：待裁）：**表格化手动编菲**——点击色码格输入**层数**、指定裁床师傅，批量生成菲票；**裁床单打印** + **菲票打印**（二维码菲票，浏览器打印）。
3. **车间进度**：订单列表 → 详情页：**生产进度环**（演示中 0%→8.33%→25%→50% 实时变化）；**「关键工序」开关**；三个视图 tab：按菲号显示 / 按工序显示 / **员工工资统计**；按扎号分列卡片，每扎列工序+单价（裁剪 ¥5 / 车缝 ¥6 / 洗水 ¥2 / 包装 ¥0.5）+ 已完成进度。
4. **协助登记**：管理员可**代工人登记**——选择工人 → 选择工序 → **批量登记** → 登记完成；支持**批量撤销**。
5. **修改数量需填写原因**（数量修正强制留痕）。
6. **薪资管理**：四个 tab——工资条 / 扫描统计 / 薪资结算 / **员工计件明细表**；「结算/撤销」按钮；隐藏空记录、**仅显示未设置单价的记录**开关；按工人分组明细（订单/款号/工序/数量/单价/金额+合计）；**薪资条打印**（确认金额 → 浏览器打印/存 PDF，可选页数份数）。
7. **质检管理**（独立模块）：字段——图片/工序名/工厂订单号/款式编号/款式名/**菲票编号/返修原因/状态（返修中）/返修数量/收回数量/计件数量/生产人/质检人/质检时间**；行操作：详情、收货、完成、删除；**导出 Excel**。
8. **报表中心四表**：工序生产对照表 / 订单计菲明细表 / 订单进度明细表 / 裁床生产工序表（按订单/款式/工序筛选，含可登记数量列）。
9. **工作台首页**：KPI 卡（本月订单、实裁数、本月生产）+ 实裁数趋势图 + 产能对比柱图 + 订单超额表 + **总完成百分比环图**。

## 四、差距清单（按建议优先级）

> 仅分析。是否立项由用户拍板。

| # | 差距 | 等级 | 说明与建议方向 |
|---|---|---|---|
| GAP-0 | **PC Web 管理端** | 结构性 | 竞品 PC 优先：厂长/文员录单、编菲、打票、看报表都在电脑。我方纯小程序在办公室场景吃力（小屏录色码矩阵、打票依赖云打印）。建议方向：不做全量 Web，先评估「后端已 157 路由 + Vue admin（kanban_template 有 Vue3 配置端先例）」的最小 PC 台账端（订单/看板/报表/导出四页即可止血）。 |
| GAP-1 | **质检管理模块** | 高 | 返修原因/返修数量/收回数量/质检人/状态流转/按菲票挂账/导出 Excel。服装车间刚需，直接关联工人计件（返修扣减）。P3 立项方案落盘时应把质检从「附注」提为与委外同级的正式域。 |
| GAP-2 | **协助登记（批量代登/批量撤销）** | 高 | 竞品：选工人→选工序→批量登记，且可批量撤销。适用场景：无智能手机的工人由组长代登、整批返工重登。我方已有单人撤销，差「按工人/按工序批量」与「代登」动线。 |
| GAP-3 | 登记数量修改强制填原因 | 中 | 竞品改数必填原因（留痕字段）。我方 AuditLog 底座现成，只差「原因必填」校验 + 时间线展示原因字段。成本低收益高。 |
| GAP-4 | 薪资条打印 | 中 | 竞品按工人出薪资条（确认金额→打印/PDF）。我方云打印/打印历史底座可复用；微信侧也可走订阅消息推送工资条（与差距 #4 订阅消息同一外部依赖）。 |
| GAP-5 | 外发/委外管理 | 中 | 竞品有独立外发模块。与 P3「计划委外」重合——落盘 P3 方案时对齐竞品字段（外发数量/收回/外发单价/对外发厂计账）。 |
| GAP-6 | 工序「是否开放工价」开关 | 中低 | 竞品可按工序隐藏单价（不让工人看到工价，防攀比）。我方工价页已标计价链（床次>款式>默认），加一个 per-工序可见性开关即可，前端扫码页按 effective_perms/字段过滤。 |
| GAP-7 | 报表导出 Excel | 中低 | 竞品质检/报表均可导出。我方报表均在看板页无导出。小程序侧可先做「生成 xlsx 下载」（后端 openpyxl + 文件下发），成本低。 |
| GAP-8 | 「关键工序」聚焦开关 | 低 | 进度详情只看关键工序产量。我方 dim 看板加一个工序白名单过滤即可，优先级最低。 |
| GAP-9 | 打版/样菲流转 | 低（缓） | 面向自有版房工厂，与我方中小加工厂定位偏离，缓做不做均可。 |

## 五、我方领先项（无需动作，保持）

1. **一线扫码体验**：扫码→手输码兜底→离线暂存→语音报数→大字号，竞品手机端仅为辅助。
2. **AI 报表问答**（GLM 自由问答 + 全域查询方案 B + 留痕缓存）：竞品完全未见。
3. **审计/追溯底座**：AuditLog 全链 + 订单留痕时间线 + 质量追溯页，比竞品「改数填原因」更系统化。
4. **成本/仓库/定额领料**（P1 已交付）：竞品教程未展示同深度能力。
5. **云打印 + 打印历史 + 回看补打**：竞品靠浏览器手动打印。
6. **权限点体系**（28 点 + 宫格显隐）与**多厂隔离**。
7. **报价→订单→出货→应收**全 ERP 后链路（P1/P2 已交付）。

## 六、结论

- 竞品在**办公室侧（PC 端、质检、外发、批量代登、导出）**明显领先；我方在**车间侧（扫码动线、AI、追溯、成本）**领先。两者正好互补——竞品的强项集中在我方「坐办公室的人」的场景，我方强项集中在「拿手机的车间的人」的场景。
- 若只做三件事补差距，建议顺序：**GAP-1 质检（并入 P3 一起立项落盘）→ GAP-2 协助登记 → GAP-0 最小 PC 台账端评估**；GAP-3/4/6/7 为低成本增强可穿插。
