# 系统测试设计与用例：全角色 × 全流程 × 异常场景

- 设计与执行：资深测试专家（Claude fork），2026-11-02
- 测试对象：扫菲（衣计）小程序 + Django 后端，含当日 P2.5 安全库存/自动采购建议、订单损益视图、报价转单回写等最新改动
- 分层口径：
  - **L1 套件级**：单域断言脚本（31 个 `test_*.py`/`e2e_*.py`，manage.py shell exec 跑法）
  - **L2 域端到端**：单域内 API 全链（建→改→流转→撤/删→隔离）
  - **L3 跨域流转**：报价→订单→BOM→采购→到料→领料→开床→扫菲→出货→应收→核销→成本→工资 十七环
  - **L4 异常与安全**：401/403、跨厂隔离、软删、并发、重复提交、终态守卫、换算缺参、离线边界
- 状态标记：✅=自动化已覆盖且本轮绿 ｜ 🟡=本轮新补 ｜ ⚠️=无自动化覆盖（差距，见 §五）｜ ❌=本轮发现缺陷（见 §六）
