> 2026-10-20。配套 docs/系统重设计实施方案.md。目标：分支覆盖率 ≥80%（coverage.py --branch，范围 apps/*）。
> 现状基线：2026-10-17 实测 branch 75.0% / 行 88.2%；既有套件合计 449 断言（111+53+24+54+10+34+36+50+27+20+102 契约）。

## 一、测试分层架构

```
L1 后端逻辑/分支套件（主力，in-process django.test.Client + coverage.py --branch）
   ├─ 既有套件（回归底座，可运行性见 T0 处置：perm_points 27/plan_a2 20 确认可跑；
   │   e2e/audit/trace/kanban 等旧种子套件先修复或归档）
   └─ 新增 5 套件（本设计产出：test_orders / test_stats_refactor /
      test_kanban_link / test_scan_enhance / test_salary_edge）
L2 契约测试 contract_check.py —— 102 路由 0 未匹配，新端点必须同步登记
L3 UI+后端融合套件（automator，真链路：UI 动作 → API 落库 → UI 回显三层断言）
   ├─ 既有 ui_offline / ui_fullchain / ui_salary 等
   └─ 新增 ui_orders / ui_bed_wizard / ui_scan2 / ui_kanban_drill
L4 真机人工清单（automator 覆盖不到：真扫码摄像头、分享、订阅消息）
```

- L1/L2 产出覆盖率门禁数字；L3 保证「页面按钮真的连着对的接口」；L4 一页 checklist。
- 所有 L1 套件幂等自清扫（复用 perm_points_tests 的测试厂模式）；不依赖 DB 现状。
- **回归底座处置（T0，INT 在阶段一前完成）**：旧套件（e2e_fullchain/wave2/e2e_edge/e2e_branches/trust_verify/audit_fixes/traceability/kanban_template）硬编码 company_id=2 种子，DB 重置后不可直接运行。处置：①先把 setup 改为动态建厂（复用测试厂模式，只改 setup 不改断言），跑通即恢复为回归底座；②跑不通的移入 `backend/legacy_tests/` 归档，文件头注明替代覆盖来源（新 5 套件 + L3 融合套件）。各 agent 的「回归绿」门一律以 T0 决议清单为准，禁止引用未修复的旧套件制造假绿。
- **权限字典同步**：新增 orders.manage 后 ALL_PERMISSION_KEYS 由 34→35，perm_points_tests / plan_a2_tests 中硬编码的点数/组数期望须由 SA1 同步更新，防回归断言失真。

### 2.1 数学账（如何从 75% 到 80%）

## 四、L3 融合套件设计（automator，uitest/ 目录）

统一三层断言模式（沿用 ui_fullchain 教训）：①UI 动作成功 → ②API/DB 落库正确 → ③回到 UI 回显一致。wsEndpoint 9420；mock wx 自定义函数返回 errMsg；脚本置 uitest/。

| 套件 | 动线 | 关键断言（每条 3 层） | 断言数 |
|---|---|---|---|
| ui_orders.js | 宫格→订单管理→新建（矩阵）→保存→列表回显→详情完成率→＋开床跳向导 | 列表卡片字段=API 返回；完成率与 L1 计算一致；落后格红底 | ≥12 |
| ui_bed_wizard.js | 订单详情→开床→4 步向导（挂单余量预填/超量确认弹窗/生成扎/打印引导可跳过）→回订单详情床次数+1 | 每步禁用态；**第 4 步尾扎预览「整除 N 扎+尾扎 M 件」与手工计算一致**；POST body 含 order_id；床次列表出现新床次 | ≥14 |
| ui_scan2.js | 扫菲：满扎徽标「96/100」渲染→手输码入口（床次+扎号）→候选列表→选中登记→离线断网入队→联网补传 | 徽标数据=selector 返回；补传后 workbench 件数+1 | ≥12 |
| ui_kanban_drill.js | 看板行 tap→床次列表（预过滤参数正确）→菲票→登记明细→**返回后筛选状态保留**；订单页签→订单详情；link=order 单号 tap | 每级 navigateTo URL 参数断言；回显数字=接口值；navigateBack 后页面查询参数未丢 | ≥10 |
