# 第一部分 系统总览

## 1.1 三层业务架构

```
┌─ 订单层（老板/跟单视角）─────────────────────────┐
│  订单：客户/交期/颜色尺码数量分解/整体完成度/交期灯    │  ← P1 新建
├─ 执行层（厂长视角）───────────────────────────────┤
│  裁床：床次计划/编菲生成扎/锁定/裁完/菲票打印          │  ✅+P2向导化
├─ 计件层（工人视角）───────────────────────────────┤
│  扫菲：扫码→工序→登记→当日撤销；薪酬=快照结算          │  ✅（业界最优形态）
└─ 支撑层 ────────────────────────────────────────┘
   组织权限(公司/岗位/权限点) 客户/工序/款式档案 仓库批次/追溯
   看板(口径唯一+三层受众+下钻) 通知/审计/客户端日志 设置(14开关)
```

## 1.2 核心主链路（数据流）

```
订单(颜色×尺码数量) ─┐
                     ├→ 建床向导 → 床次 Production(plan_qty,锁定,裁完)
款式(工序工价) ──────┘              └→ 菲票扎 Ticket(二维码,打印)
                                        └→ 扫菲登记 Record(qty×单价快照)
面料批次 Lot ←入库单                     │      ↓
   └→ 血缘 ProductionLotLink ←领料单     └→ 结算单 Settlement / 结算申请 SettleApply
                                              ↓
                                    看板（口径唯一 stats.py，全下钻）
```

# 第二部分 详细业务流程

## 2.1 注册登录与多公司

### 2.1.1 登录 ✅

- **触发**：打开小程序未登录。
- **主流程**：①手机号+验证码（60s 防重发、每日 20 条）或手机号+密码 → ②签发 token → ③拉公司列表：无公司→创建公司引导；1 家→直达首页；多家→选厂页（显示岗位名）。
- **异常**：微信登录（openid 关联，手机号可空）；token 过期→自动登出回登录页（已有自动化断言）。

### 2.1.2 创建公司 ✅

- **触发**：登录后无公司，或「我的」→创建。
- **主流程**：填名称（城市可选）→ 系统自动：生成公司编号（100001 起自增）、播种 3 个系统岗位（管理员=全部权限\*；裁床、车间=细粒度点集）、播种 10 个常见工序（裁剪/车缝/锁边/烫工…）、初始化 14 项公司设置、灌默认看板模板 → 创建人自动成为在职管理员 → 直达首页。
- **权限**：任何登录用户。

### 2.1.3 加入公司 ✅

- **主流程**：①管理员出示公司二维码（公司编号生成；任何微信扫码→识别 `JOIN:` 前缀→确认加入）或口头告知编号 → ②员工扫一扫/输编号提交申请（PENDING）→ ③管理员收到通知 → 员工管理审核。
- **审核（approve）**：校验在职容量（按套餐 capacity：体验 20/基础 50/标准 150/旗舰 500）→ 通过设岗位 → ACTIVE。拒绝后该人可重新申请。
- **异常**：已是成员 400；容量满 400。

### 2.1.4 切换公司 ✅

「我的」→切厂 ActionSheet（公司名+岗位名）→ switchCompany（写 last_used_at）→ 重拉全局数据+权限点（effective_perms）。所有接口带 `X-Company-Id` 隔离。

## 2.2 组织与权限

### 2.2.1 岗位管理 ✅

- **主流程**：岗位列表（数量头/管理员徽标/成员数/权限点标签）→ 新建/编辑弹窗：名称（常用词点选）+ 权限点分组勾选（15 组 28 点字典驱动；「全部权限」=存 `*`）→ 保存。
- **分支**：复制岗位（自动命名"副本/副本2…"去重）；删除（有成员挂岗被 PROTECT 拦，先转岗再删）；系统岗位不出现删除项。
- **兼容**：旧 coarse key（styles/production 等）回显时自动展开为组内勾选，保存后落细粒度点；后端 has_perm 永久兼容存量。

### 2.2.2 员工管理 ✅

- **主流程**：列表（tab=在职/待审/离职 × 岗位筛选 chips × 关键字搜姓名手机号）→ 卡片：置顶、⋯菜单（设岗位/设组/离职/复职）、姓氏色块头像+性别角标。
- **邀请**：手机号+姓名+岗位（待审状态，审核后生效）。
- **离职**：有未结算记录→400 提示先结清（force 可强离）；离职工资保留可查（ACTIVE+RESIGNED 口径）。
- **复职**：容量校验。
- **指定工序**：给员工配置指定工序 id 列表（决定其扫菲工序选择器内容，见 2.5.1）。
- **组编号**：1~999（排单/组排行用）。
- **权限**：全部动作走 `employees.manage`（此前提权洞已堵）。

### 2.2.3 权限判定 ✅

`has_perm(uc, key)`：管理员岗或 `*` → 全过；细粒度点直配；旧 coarse key 按 legacy 覆盖表展开（高危点不覆盖——可收权）。`effective_perms` 随接口下发，前端宫格/按钮按点显隐，后端 403 兜底。

## 2.3 公司设置 ✅

14 项开关（KV）：裁完自动标记〔🔴 建议：改纯人工标记，向导内勾选〕、仅当月可撤、隐藏扫菲单价、过滤 0 数菲票、显示裁货总数、隐藏款式总单价、隐藏员工工资、未审核禁登记、默认计数开启、显示款式图、默认打印方式、云打印机、菲票标签样式、个性化通知。设置页管理员逐项开关，实时生效。

## 2.4 基础档案

### 2.4.1 客户与分组 ✅

客户：编号留空自动生成（KH0001 顺延，含软删防撞号）、名称/电话/分组/备注；分组 CRUD；删款式不受客户影响（SET_NULL）。

### 2.4.2 工序档案 ✅

固定工序（全员默认可选）/非固定（指定工序）；默认单价（0 价工序合法存在但**不可报工**）；排序；建司自动播种；管理员长按删除（被款式使用/有登记时拒删）。小程序工序页管理员可新建。

### 2.4.3 款式 ✅

- **建档**：款号（公司内唯一）/名称/客户/图片（上传自动压缩，相对路径存储）/备注。
- **工序工价配置**：`process_items[{工序,单价,排序,允许跳序}]`，保存自动汇总款式总单价；支持 partial 更新。
- **复制**：款号需改（唯一约束）；**删除**：有床次引用 400「无法删除」。

## 2.5 订单管理（P1 新建，🔴 参数取〔建议〕值）

### 2.5.1 新建订单

- **触发**：订单管理→「＋新建」；或客户详情→「给该客户新建订单」。
- **主流程**：①单号（留空自动生成，〔建议〕`SO` + 4 位公司内顺延，软删防撞）→ ②客户（可选）→ ③交期（可选，给了才有交期灯）→ ④订单类型（自产/外发）→ ⑤颜色×尺码数量矩阵（复用编菲矩阵交互：历史颜色/尺码点选+自定义）→ 保存。
- **数据落点**：Order + OrderItem（每色码一行 qty）。
- **校验**：同单同色同码唯一；总数量>0。

### 2.5.2 订单详情与完成度

- **主视图**：色码矩阵每格显示「订单数 / 已登记 / 完成率」；汇总行=整单完成率；交期灯（绿=充裕、黄=距交期≤〔建议 7〕天、红=过期未完成）。
- **完成度口径**：分子=该订单全部挂单床次的菲票登记聚合（按色码），走 stats.py 唯一口径；分母=OrderItem.qty。
- **关联床次列表**：点击跳床次详情；「开床」按钮直达建床向导（预挂本单）。
- **状态机**：生产中 →（手动）已完成/已取消；全部色码登记满时系统提示一键标完成。已挂床次的订单**不可删只可取消**。

### 2.5.3 挂单规则

- **可选挂单**〔建议〕：散单/翻单允许无单开床；订单看板底部单列「未挂单床次」汇总行。
- 挂单开床时：颜色尺码余量自动带出，**录入超订单剩余量时拦截确认**（提示"超过订单数量，确认继续？"——防手误，不硬禁）。
- 存量床次（source_order_no 文本）不回填；`source_order_no` 保留为外部单号字段，挂单时自动带出。

### 2.5.4 交期预警（P3）

交期前 N 天〔建议 7〕站内通知管理员（复用通知模块）；过期未完成每日一条。

## 2.6 编菲/生产（P2 向导化）

### 2.6.1 建床向导（4 步一气呵成）

| 步 | 内容 | 要点 |
|---|---|---|
| 1 选单选款 | 有单：从订单进入（带出客户+色码余量）；无单：直接选款式 | 订单入口可跳过此步 |
| 2 裁剪计划 | 床次号（预填最大号+1）/ 计划数 plan_qty / 面料（历史点选）/ 来源单号 / **裁完自动标记勾选（默认关）** | 床次号公司内唯一 |
| 3 工序工价 | 整段带出款式工序价，可逐条覆盖（订单工序 ProductionProcess） | 0 价工序行警示（登记时会被 0 价拦截） |
| 4 生成扎 | 颜色×尺码矩阵 + 扎号规则 + 起始扎号 → 确认生成 | (床次,扎号) 冲突自动顺延；件号/布料可选 |

- **生成成功**：落床次详情页，引导打印菲票（可跳过）。
- **权限**：production.manage。

### 2.6.2 床次管理 ✅（向导后为管理+快捷操作）

- **列表**：缩略图/款号/床次号/裁货数/登记进度/锁定/裁完筛选；快捷开关：锁床、裁完（P2 提升到列表）。
- **锁定/解锁**：拦截该床全部菲票**新登记**（防错登/已结款），需 production.lock，写审计；解锁同权。
- **裁完标记**：纯状态（不拦登记/不拦加扎——2026-10-18 拍板），人工标记〔🔴 已建议向导勾选+列表快捷开关〕。
- **删除**：同事务级联软删菲票；有登记记录时拦截。
- **详情页**（瘦身）：菲票列表（按色/码/扎）、存量工序配置可改、锁定/裁完、追溯卡片、打印入口。

### 2.6.3 加扎/编菲矩阵 ✅

床次详情→加扎：同向导第 4 步矩阵；锁床后禁加扎。

### 2.6.4 菲票打印 ✅

- **流程**：选择菲票（单张/整床批量，分页拉全护栏 5000）→ 预览（所见即所得，computeLabelLayout 同源）→ 蓝牙发送（逐张，进度 x/N）→ print_count 回写。
- **模板**：纸张 40×30/60×40/50×80、二维码大小、数量放大、字段点选、**每机偏移 print_label_offsets**（对位诊断签校准）；仅 TSPL。
- **异常**：断连自动入重试队列→打印管理补打；蓝牙不可用提示。
- **打印管理页**：打印机绑定/试打/对位诊断/偏移微调（print.manage）。

## 2.7 扫菲（计件层，✅ 主体）

### 2.7.1 扫码登记（主流程）

1. 扫菲页扫码（或相册识别）→ 解析 7 段二维码（公司编号|床次|款号|扎号|颜色|尺码|数量）→ 校验本公司菲票（跨厂票提示）。
2. 工序选择器：固定工序 ∪ 本人指定工序（单选项免选直达）；**0 价工序灰显「未上价」禁选**（员工差评防护）。
3. 数量：默认整扎；**同扎同工序全员累计 ≤ 扎数**（超限拒绝）；同票同工序同人再次登记=**增量累加**（单价沿用首次快照）。
4. 提交 → 成功反馈（累计件数）→ 连续扫码模式（提交后自动回相机）。
- **P0 增强——满扎提示**：扫码即显示该扎该工序「当前累计/扎数」，工人先看再登。

### 2.7.2 手输码兜底（P0 新增〔建议〕）

扫码失败/码破损 → 「手输查询」：输入床次号+扎号 → 列出匹配菲票 → 选中走同一登记流程。**不新增权限点**（仍 records.create）；查询接口限本公司。

### 2.7.3 离线暂存（✅ 已有基础，可选增强）

现状：请求失败自动入本地队列，网络恢复 onShow 自动补传（有自动化断言覆盖）。🔴 可选增强：显式离线模式开关+暂存列表查看/手动重发——弱网车间真实痛点，工作量小。

### 2.7.4 撤销登记

| 情形 | 规则 | 权限 |
|---|---|---|
| 本人当日 | 当天撤自己的（开关"仅当月"叠加校验） | 无需点 |
| 撤他人 | 任意时间的他人登记 | records.revoke（管理员岗恒过） |
| 已结算 | 一律不可撤（快照锁定） | — |
| 跨日修正 | 本人不可，找管理员/持点岗位代撤（**路径已存在**，写撤销审计） | records.revoke |

> 注：调研报告提的"管理员代撤销缺失"经核实为误报——管理员可撤任意登记且写审计，已有路径。

### 2.7.5 协助扫菲 ✅

登记时选他人：目标须本公司在职成员（硬拦截），需 scan.assist 点；审计记录操作人。**次品/返工**：🔴 待拍板（建议二期做双数量模型预留：Record 预留 qty_defect 字段位，次品率报表后置）。

## 2.8 薪酬 ✅

### 2.8.1 计件工资构成

工资 = Σ(登记 qty × 登记单价快照) ± 工资调整 ± 固定工资（UserCompany.fixed_salary 按天/月）。四次价格快照链（订单工序价→款式工序价→工序默认价→登记快照）保证改价不影响历史。员工端感知（P0）：工作台常驻「今日件数 / 今日预估工资」〔建议，业界第一 ROI；不受"隐藏员工工资"开关影响——那是看别人的〕。

### 2.8.2 结算单（salary.settle）

按期间把未结登记锁定为金额快照（全员或指定员工）；撤销结算（settle_revoke）：该期间已发放（PAID）申请重叠时 400；撤销后登记回到未结。

### 2.8.3 结算申请审核流（员工自助）

申请（本人，期间+未结金额快照）→ 待审核 → 管理员：通过（待发放）/拒绝（理由）→ 发放（生成结算单+锁定登记）/作废。状态机 0→1→2/3/4，全程通知。

### 2.8.4 工资调整（salary.config）

±金额+事由，进当期工资，审计留痕。

## 2.9 看板体系（P0/P1 改造）

### 2.9.1 口径服务（P0 地基）

`apps/production/stats.py` 唯一实现：床次进度、款式行、订单完成度（P1）、范围汇总（完工=配满工序/在制=已登未满/已裁=新建床裁货/登记）。消费方：工作台、dashboard、计划表、款式页、订单页——改口径只动一处。

### 2.9.2 工作台（工人，✅+P0）

进行中床次进度 + 本人今日登记 + **今日件数/预估工资常驻**（P0）。

### 2.9.3 生产看板（厂长，✅+P0 下钻）

- 时间 6 档 tab；汇总卡（完成/在制/已裁/登记+存量）；生产计划表（款×色行、真合并、块底色交替）；近 7 天柱图；工序占比 Top6；员工排行 Top10；组排行。
- **下钻（P0）**：列驱动模板 extra 加 `link` 配置——计划表行→床次列表（预过滤款号）→菲票→登记明细。

### 2.9.4 订单看板（P1 新建，老板/跟单）
