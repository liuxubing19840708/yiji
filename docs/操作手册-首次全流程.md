# 衣计小程序 · 首次使用全流程操作手册

> 适用场景：全新数据库，从零开始把一家服装厂的完整业务在系统里跑一遍。
> 角色约定：**老板（管理员）** = 你自己；**员工** = 至少再准备 1 个手机号（真机第二台，或同一台手机退出重登）。
> 日期：2026-10-18（当前版本 V1.0.0）

## 1. 管理员首次登录 · 创建公司

1. 打开小程序 → 登录页，切到「**验证码登录**」：输手机号 `13800000001` → 勾选协议 → 「获取验证码」→ 去后端日志看验证码 → 输入 → 登录。
   （也可以用「密码登录」，密码 `yisao1234`。）
2. 因为此前你在这家公司，清库后公司已清空：会进入「**创建公司**」引导 → 填 **公司名称**（必填）、**所在城市**（选填）→ 创建。
3. 创建成功自动进入首页工作台，你成为该公司的**在职管理员**。记住系统生成的 **6 位公司编号**（后面邀请员工要用，也可在「我的 → 切换公司 / 后台 → 公司」里查）。

> 系统已自动创建 3 个内置岗位：管理员（全部权限）、裁床（款式+生产+工作中+我的薪酬）、车间（工作中+我的薪酬）。

## 2. 基础设置

### 2.1 工序档案（新公司已自动预置）
1. **建公司时系统已自动预置 10 个服装行业常见工序**：裁剪、车缝、锁边、烫工、钉扣、锁眼、洗水、质检、整件（已开固定开关）、包装——单价均为 0（未上价），到款式「工序单价」里按款式上价即可。
2. 缺的工序可在小程序内补：底部 Tab「**工序**」→ 管理员右上角「**＋ 新建工序**」→ 填名称、默认单价（选填）→ 创建，列表里可打开「固定工序」开关。
3. 也可以在浏览器后台 http://127.0.0.1:8000/admin/ →「工序」里增删改（13800000001 / yisao1234）。

### 2.2 客户管理（可选，建议建 1~2 个）
首页宫格「**客户管理**」→ 可先「添加分组」（如 内销/外单）→「新建客户」：客户编号 / 名称* / 手机号 / 备注 / 分组。

### 2.3 邀请并审核员工
1. **管理员**：首页宫格「**员工管理**」→「⊕ 邀请员工」→ 填员工手机号（如 `13900000002`）、姓名、可不选岗位 → 「发送邀请」。
2. **员工侧**（第二台手机或退出重登）：用手机号 `13900000002` 验证码登录 → 无公司引导页「输入公司编号加入」→ 填 6 位公司编号 → 申请。三种「扫码/分享」方式：① 分享卡片（公司二维码页点「分享」，点开自动预填编号）；② app 内扫码（登录后在「扫菲」Tab 扫老板的公司二维码，识别 JOIN 码一键申请）；③ 微信「扫一扫」直达小程序（需在 backend 配置 WECHAT_APPID/WECHAT_SECRET 后自动切换为小程序码，未配置时为文本码仅支持①②）。
3. **管理员**：员工管理「待审核」Tab → 「通过」。通过后员工正式入职。
4. 顺手配置：员工行「⋯」→ **设置岗位**（如裁床/车间或自建岗位：岗位管理页可自建并配权限）、**设置组**（1组/2组，影响看板组排行）、「指定工序」（给员工指定他可做的非固定工序）。

## 3. 款式与工序单价

1. 首页宫格「**款式管理**」→「＋ 新建」：**款号**（如 A2026-001）、**名称**、图片（可选）、客户（可选）、备注 → 保存。
2. 款式卡片「⋮」→「**工序单价**」：「＋ 添加工序」从档案逐个加（裁剪、车缝…），每行填 **单价**（如 0.5）+ **跳序**开关（开=员工可跳过此工序直接做后面的；关=必须按顺序完成）→「保存配置」。
   - ⚠️ **单价 0 = 未上价**，员工扫菲该工序会被拦截。
   - 款式总单价 = 各工序单价之和，自动算。

## 4. 新建床次订单 + 编菲

1. 款式卡片点「**编菲**」（或生产管理走新建）：填 **床次号**（纯数字，自动预填上一床+1）、**订单类型**（自产/外发）、**客户**、**总量（件）**、**计划裁货（件，选填，与实裁分账）**、**来源单号**（客户订单号，质量追溯用）、**面料** → 保存 → 自动进入编菲矩阵。
2. **编菲矩阵**：
   - 添加**颜色**（如 黑色、白色）和**尺码**（默认 M/L/XL/XXL/3XL）；
   - 在「横向/纵向」页签点格子填各色各码件数（某色第一格填数会自动带满整行）；
   - 或用「倍数 / 排列」页签快速铺量；
   - 「**扎号**」页签：设 **起始扎号**（默认 1）+ **每扎上限**（默认 20）→ 自动拆扎；
   - 「**匹号与物料**」页签：可填布匹匹号、面料明细（追溯用）。
3. 提交 → toast「已生成 N 张菲票」。每张菲票自动生成二维码：`公司编号|床次号|款号|扎号|颜色|尺码|数量`。

## 5. 打印菲票

1. 首页宫格「**打印管理**」→「扫描绑定」连接蓝牙标签机（BLE 扫描 3 秒）。
2. 配**菲票版式**：纸张尺寸、码大小、要打印的字段 chips（可勾上「来源单号/面料批次号」）、上下左右微调（有「对位诊断」标签辅助）。
3. 「测试打印」试打一张（试打码可直接拿去扫菲）。
4. 批量打印：生产管理 → 床次卡片「⋮」→「**打印**」→ 选「全部打印 / 仅未打印」→ 逐张打。失败自动入重试队列，回打印管理「一键补打」。

## 6. 员工扫菲（核心日常）

员工登录后底部 Tab「**扫菲**」：

1. 相机对准菲票二维码 → 弹出菲票卡（款号/床次/扎号/颜色/尺码/数量/已登记件数）。
2. **选工序**：chip 列表 = 固定工序 ∪ 本人指定工序；未上价的置灰禁选。
   （先到「工序」Tab 把常用工序的**固定开关**打开，比如「整件」，否则提示无可选工序。）
3. **录件数**（数字键盘，缺省=整扎数）→「确认登记」→ toast「登记成功」，顶部显示「今日累计 X 件 ¥Y」→ 自动继续扫码。
4. 防错规则：床次锁定禁登、重复超量拦截（累计≤扎数）、跳序拦截、单价 0 拦截；弱网自动存离线队列，恢复后自动同步。
5. **协助扫菲**（管理员）：首页宫格「协助扫菲」→ 选员工 → 扫菲页顶部出现「正为『XX』登记」，登记记在对方名下（不留金额条）。

## 7. 记件记录与撤销

- 员工：首页「**工作中**」看在制床次进度 + 本人今日登记，本人当日可**撤销**。
- 管理员：同样在「工作中」，可撤销当月内任何人的登记（未结算的）。撤销后由员工重新扫菲。

## 8. 工资结算

**员工视角**（或管理员查他人：薪酬管理 → 员工卡 ⚙）：
- 「我的薪酬」：已结/未结金额、工资/计数/固定工资三 Tab、按日期/床次/工序钻取；底部「**申请结算**」（填备注，按自然月）。

**管理员视角**（两条路任选）：
1. **主动结算**：首页「薪酬管理」→ 选日期段 →「工资结算」→ 逐员工确认 → 「确认结算」→ 生成结算单，该期间登记转已结。「结算记录」可撤销（已发放的不可撤）。
2. **审批申请**：薪酬管理「申请记录」→ 待审核「通过/拒绝」→ 待发放「**发放**」（确认已线下打款）。
3. **离职结清**：员工管理 →「办理离职」→ 有未结记录时会被拦截「请先完成薪酬结算」→ 结清后再办离职。离职后其历史工资仍可查；可复职。

## 9. 生产看板 + 模板配置

- 小程序首页宫格「**生产看板**」：时间范围筛选；顶部在制/完工/已裁/登记汇总；**计划表**（按下单日期分组、款号+下单日期块合并显示）；登记排行 / 组排行 / 工序占比。
- 新公司没有模板时自动使用**内置默认模板**（11 列），不会白屏。
- 自定义列：桌面快捷方式「看板模板配置」→ http://127.0.0.1:8000/api/kanban-admin → 登录（13800000001 / yisao1234）→ 工具栏填公司数字 ID（在后台「公司」列表可查）→ 新建/编辑模板：选字段、公式、合并方式（块合并/同值合并）、列宽（留空=自适应）、两级表头分组 → 保存 → 小程序看板即生效。仅管理员可见此入口。

## 10. 仓库与质量追溯（闭环演示）

1. **入库建批次**：首页宫格「**轻量仓库**」→「采购」Tab 新建采购单（供应商/面料/颜色/数量）→「确认」；切「入库」Tab → 新建入库单：面料/颜色 + **批次号**（沿用供应商原始编号，如 `LOT-2026A`）+ 数量 → 确认 → 自动生成面料批次。
2. **领料挂血缘**：「领料」Tab → 新建领料单：**选床次** + **选批次** + **用量** → 确认 → 自动写入「床次×批次×用量」血缘。（也可在床次详情「质量追溯」卡手工挂批次。）
3. **床次补录**：生产管理 → 床次详情 → 「来源单号」填客户订单号保存。
4. **出问题反查**（模拟客诉）：
   - 首页宫格「**质量追溯**」→ 反向追溯：输款号/颜色 → 定位床次 → 看批次血缘、菲票汇总、登记时间线；
   - 或扫任意菲票码 → 全链路详情；
   - 或批次追溯：输 `LOT-2026A` → 正向看受影响的所有床次/菲票/客户。
